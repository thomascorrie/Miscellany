# Miscellany documentation

![Logo](../Miscellany/Resources/Images/Large/Miscellany.About.Miscellany.Large.png)

Documentation for **Miscellany**, a package of miscellaneous nodes for Dynamo.

![Nodes](../Samples/Miscellany-Samples-Nodes.png)

## Nodes

- [Container Packing](container-packing.md): packing Items into Containers with the EB-AFIT algorithm
  - [Container](container.md): the entity Items are packed into
  - [Item](item.md): the entity to be packed
  - [PackingService](container-packing.md#packingservice): the packing nodes
- [Geometry](geometry.md): scalable displays of CoordinateSystems, Planes and Vectors
- [List](list.md): list utilities
- [Maths](maths.md): number conversions and running totals
